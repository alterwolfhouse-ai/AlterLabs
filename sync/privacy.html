Privacy by architecture.

Effective 17 July 2026

Your selected media stays on your device. AlterSync has no account, upload endpoint, cloud media store, server renderer, analytics SDK, or remote rendering fallback.

What AlterSync processes

When you choose video or audio, your browser reads the files locally to create previews, waveforms, edit decisions, and the final MP4. Filenames, frames, audio samples, project content, and exports are not sent to AlterLabs or a third party.

How export works

Supported browsers use their built-in WebCodecs H.264 and AAC encoders, with a same-origin JavaScript media toolkit for reading and assembling the MP4. If compatible local codecs are unavailable, AlterSync explains the limitation; it does not upload your project to finish elsewhere.

Storage and cleanup

Project media and edit state are session-scoped and kept in browser memory. AlterSync does not store project media in localStorage, IndexedDB, Cache Storage, or a service worker. Removing media, resetting a project, closing the tab, or completing/cancelling an export releases application-held object URLs and processing resources. Files you intentionally download are then governed by your browser, device, and backup settings.

Network activity

The application loads its interface and code from alterlabs.in. It does not initialize product analytics or transmit media telemetry. Standard web-host access logs may contain technical request information such as IP address, browser user-agent, requested static file, and timestamp; they do not contain the media files selected inside AlterSync.

Permissions

File access starts only after you choose or drop a file. This release does not request camera, microphone, location, contacts, notifications, or background-processing permission.

Your controls

  • Use “New project” to clear the current in-memory workspace.
  • Close the tab to end the session.
  • Do not use confidential source media on a shared or untrusted device.

Contact

Questions about this privacy boundary can be sent through the contact channel on AlterLabs.
